# Pre-semantic-moves-v1 archive

Snapshot created on 2026-08-09 during the experimental reset.

These files preserve the detailed history of the collaboration, raster, and
cost-shaping investigations. They are archived because some experiments used
`moves` to include network-specific controller actions. The current contract
charges only semantic braid/knot operations. Historical qualitative lessons may
be cited from active notes, but historical objective values, leaderboards, and
checkpoints are not admissible evidence for the new comparison.

Nothing in this directory is a starting checkpoint for the new scientist roster.
