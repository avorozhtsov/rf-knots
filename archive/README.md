# Research archive

This directory contains experiments and notes that are useful for provenance but
are not part of the current experimental contract.

The first snapshot, [`pre-semantic-moves-v1`](pre-semantic-moves-v1/), predates
the decision that the objective charges only semantic knot operations. Results in
that snapshot may charge controller-local actions such as head shifts or tape
writes and therefore must not be compared numerically with current results.
