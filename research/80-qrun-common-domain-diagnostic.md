# Common-domain Q-Run diagnostic: input and witness-access gate

2026-09-21. This is a diagnostic follow-up to79, not a replacement for the
frozen graph/control experiment69 or its independent evaluations70/74.

Before scoring any network, construct16 roots using `conjugate_witness`, seed
20261040, increasing indices0..4095, N3..8 and conjugator depth2..8. Take the
first four eligible distinct cyclic representations in each of four strata:
witness CC1/2 crossed with raw length <=20/>20. Stop when all quotas fill;
insufficient supply is a failed gate, not permission to change the selection.
All words fit L48/N12 without truncation. Require determinant greater than1
at the root and RF TRAIN ownership of every state in the explicit witness.
These are representations, not16 independent knot types. Reference CC is an
upper bound, not automatically u. This TRAIN diagnostic deliberately cannot
establish held-out generalization; Q training exposure is not established.

Write and hash the selected panel before consulting either policy. Replay
each constructive witness in the shared RF reference with ActionSpec(48,12).
Check that every witness action is in RF's ordinary-plus-four-insertions
proposal pool (these witnesses do not require insertions).

Then route the same semantic witness through each native Q254 raster and
Q304 strand-graph controller using the existing native translator, with
native action horizon128 and L10/L1000 budget observations. Load the exact
weights already verified in `qrun-baseline-input-check-v2/report.json`, without
training or checkpoint migration. Save native actions and portable semantic
witnesses and independently replay the latter. Report semantic versus native
plies separately. A routing miss is a diagnostic failure, not a proof that
the architecture cannot solve the knot by another route.

This gate uses oracle reference actions, NOT policy-selected actions. Successful
replay is not a network solve and is not an embedding-quality measurement.
It checks input compatibility and existence of an accessible successful path.
The native controller can require extra head movements; equal native action
budgets and equal RF semantic budgets are not interchangeable compute budgets.

After this gate, freeze an explicit search-comparison contract before scoring:
use these same roots, preserve native head state and budget observations,
count actual neural evaluations, distinguish greedy policy from MCTS, replay
all reported successes, and retain failures as budget-censored outcomes.
Do not infer that old Q3048/10 and RF1/64 were comparable tests. The eventual
long-input architecture must reuse learned local computations or distill their
behavior; passing this short-input gate is not long-input transfer.
