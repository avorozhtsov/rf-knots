## Question and fixed construction

The ordinary graph TRAIN pool has only10 pairs with a word longer than48 and
no such exact2 pair. Original/suffix TRAIN already contains long words, often
paired with the empty unknot. Add general long-to-long relations rather than
claiming all existing data is short or that repeated draws create new support.

The new builder uses seed20261075 and6144 fixed attempts. Intended witness CC
counts0,1,2 cycle within each of three word-length bands49..96,97..192,193..384.
Strands cycle3..33 across the bands; maximum length and strand count are finite
experimental support, not a claimed architecture limit or arbitrary-size proof.

Each reference starts with the cyclic permutation braid1,2,...,n-1, then adds
random conjugates of squared generators. These blocks have identity permutation,
so the closure stays a knot. Conjugators have0..3 signed letters. A fixed random
target in the band is filled with genuine pure blocks, not padded solely with
inverse cancellations. Alternating deterministic blocks of attempts use positive
centers or randomly signed centers. The reference need not be an unknot.

Zero-CC pairs are cyclic rotations. Other pairs change one letter in each of
one or two distinct selected blocks; every intermediate state is recorded.
These are known finite construction families, not representative of all knots;
cyclic views and shared invariant groups are not independent knot types.

Lower bound is max(abs(signed_signature_difference)/2, determinant_difference).
The latter term is1 when determinants differ,0 otherwise. Upper bound is the
literal CC path length, or0 for an independently checked cyclic certificate.
Never convert a two-CC witness automatically into exact distance2. Compute
integer Seifert invariants on every state and cross-check every determinant
with the independent integer Burau cofactor. Fail on inconsistent bounds,
malformed braids, multi-component closures or replay disagreement.

## Readiness, not metric success

Before optimizer use, every band must have at least32 pairs and16 query groups
in EACH exact class0,1,2 for TRAIN, and8 pairs/4 groups per exact class for EACH
of DEV and TEST. Interval pairs are retained and counted separately; they do
not fill exact-class quotas. These thresholds certify minimum support only,
not adequate statistical power. All6144 attempts run, with no score-based early
stop or post-result threshold relaxation. If the gate fails, report the gap;
any extension needs a new recorded contract.

Attempt shards commit64 rows at a time with hashes and a compact progress
manifest. Resume only with explicit --resume, an exclusive writer lock,
unchanged source/input/config pins, complete shard coverage and valid stored
certificates. Preserve uncommitted or changed shards for diagnosis; fail rather
than overwrite. A completed directory is immutable and checked on resume.
Recompute selection and statistics from committed rows; never trust a saved
readiness flag without its counts. A separate post-exit consumer must recheck
selected certificates, ownership, input/output hashes and supply arithmetic
before a training experiment loads the dataset.
