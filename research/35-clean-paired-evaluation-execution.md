# Sequential execution of the clean paired evaluation

2026-09-20. Operational specification fixed before scoring either new panel.
This implements note33, without changing its training or scientific gates.
Do not edit this file while its evaluation controller is active; record results
in a separate subsequent note.

The controller is `scripts/run_clean_paired_evaluation.py`, with output
`artifacts/embedding-clean-paired-evaluation-v1/`. It waits for BOTH final
2048-step training arms. It never launches, restarts or stops training. The
launcher PID is only a discovery hint: actual command lines and manifests are
checked. Source files must remain frozen through both training and evaluation.

Before scoring, require matching configurations except output/value weight,
initial tensor hashes, architecture, data and source hashes; replay-audit and
relative-group gates must pass. Final checkpoints must have finite tensors,
matching sampling RNG states and verified hashes. No intermediate checkpoint
or validation-selected checkpoint is evaluated.

## Fixed sequential job matrix

1. Nine metric evaluations: parent/value/control on general Gordian original
   bounds and short-u original/determinant-strengthened bounds. Each evaluation
   includes the original and lifted views and constant-distance controls.
2. Four anytime cost-search evaluations: parent/value/control/length, all64
   original short-u roots,128 expansions and both CC weights10/1000.
3. Ten MCTS evaluations: parent with constant0.5 leaf value, and value/control
   each with constant0.5 and learned leaf value, separately at both CC weights.
   Use55 distinct query fingerprint groups, two seeds,512 simulations,
   widening4, root noise0.25, witness-feasible caps and default catalogue
   proposals. Selection is model-blind shortest reference witness per group.
4. Four paired cost-search comparisons and twelve paired MCTS comparisons.
   Distinguish changing weights from changing only the leaf-value mode, and
   explicitly label comparisons changing both; the latter do not isolate a
   causal value-head effect. Replay all successful witnesses and costs, preserve
   censored failures, and report new/lost/common solutions and compute.
5. One evaluation-only parent rollout collection on all64 original short-u
   roots, eight episodes per root and cost condition. The previously unspecified
   portfolio generator seed is fixed NOW to20261016, before any scoring.
   These episodes must never enter this training experiment.
6. Two stochastic-portfolio comparisons against parent constant-value MCTS
   seed0, one per CC weight. Charge actual neural work against the512 budget;
   do not pool MCTS seeds into an expanded baseline budget or assign a return
   to an incompletely charged rollout.

This totals42 jobs. They execute serially, with durable process/log/output
records and source snapshots. Every completed output is hashed and inputs are
rechecked between jobs. A controller restart verifies the exact completed
prefix and adopts only an exactly matching live child; unexpected preexisting
outputs, changed checkpoints, duplicate writers and lost partial jobs require
attention rather than silent overwriting/recomputation.

## Interpretation boundaries

The fresh panels contain66 general pairs in24 query groups and64 short-u roots
in55 groups. Independent metric-path and accepted-rollout partition audits
passed. These are synthetic tasks, and fingerprints are not knot identities.
Views, seeds and the two cost conditions are correlated observations.

This experiment tests full shared-encoder/policy/value training on a scalable
architecture, not a new residual adapter. Arbitrary input dimensions and a
large-word execution check are engineering evidence, not evidence that the
model can solve arbitrary knots. Success still requires reliable short-distance
estimates AND improved replayed search outcomes/costs. A failure is retained;
these final panels are not used to tune or promote a replacement checkpoint.
