# Проверенные альтернативы порядку witness до обучения policy

2026-09-21. Подготовка по 55 завершилась, но обнаружила всего 4 multi-positive
состояния из 19189. Следовательно, set-valued формат почти везде всё ещё
означал бы одну последовательность. До обучения расширяем положительные
множества точными локальными доказательствами; исходный набор сохраняется.

## Допустимые доказательства

Сначала проверить другие действия уже имеющегося sparse training pool:
если одно действие приводит ровно в тот же следующий raw state и с теми же
consumed CC/moves, существующий suffix подходит без изменений. Это особенно
важно для одинаковых сокращений в разных местах: policy не обязана запомнить,
какую из эквивалентных позиций предпочёл автор witness. Используется точное
равенство, а не сходство embedding или совпадение fingerprint.

Для двух соседних действий из успешного TRAIN witness попробовать поменять
порядок, корректно перенеся индексы после REDUCE. Поддерживаются непересекающиеся
не переходящие через шов локальные CC/COMMUTE/BRAID/REDUCE. Оба порядка должны
точно replay в то же raw слово, число нитей, consumed CC и consumed moves.
Неподдерживаемые/перекрывающиеся/не совпавшие случаи пропустить, не объявлять
ходы коммутирующими по сходству сети.

Для блока последовательных REDUCE рассмотреть перенос каждого последующего
сокращения на первое место через такие проверенные соседние перестановки.
Проверить каждую перестановку и ещё раз весь полученный prefix до совпадения
с исходным endpoint. Это даёт альтернативы для всего независимого блока,
не только для первых двух соседних сокращений. Комбинаторного перечисления
всех порядков не требуется. Подготовка зависит от длины witness; это не
новый блок neural inference и не фиксированный потолок размеров сети.

Добавлять новое первое действие к positive set только если исходный suffix
имеет уже записанную минимальную известную стоимость в этом state/resource
context. Не менять сам known cost, не помечать другие действия плохими.
Остальной suffix имеет существующее replay-свидетельство. Для двух CC
альтернативный промежуточный fingerprint вычислить точно и требовать TRAIN.
Если один из двух ходов zero-CC, промежуточное состояние связано им с одним
из проверенных TRAIN endpoints; это достаточное доказательство ownership.
Весь reordered REDUCE prefix zero-CC, поэтому сохраняет исходный fingerprint.

## Артефакты и ограничения

Новый output `diverse-mcts-supervision-diamonds-v1`, отдельный от v1.
Для каждого добавленного действия — certificate с condition, source witness
hash, suffix index, span и способом построения альтернативы. Для двухходового
случая хранить semantic actions; для блока — фиксированный алгоритм bubbling,
воспроизводимый из исходного witness. Перед обучением нужен отдельный replay
этих сертификатов, не только hash или число добавленных targets.

Relative coefficients не меняются: это не новые sampled MCTS trajectories.
Общие training candidate pools должны оставаться одинаковыми для positives
и preferences. Metric views и их SHA остаются прежними. Прежние trajectory,
ownership и witness ограничения не ослабляются. Новые нейросетевые веса не
добавляются, value targets не создаются, калибровка/оптимальность не заявляются.
Даже этот набор не содержит всех допустимых порядков: unsupported виды ходов,
циклический шов и более сложные перестройки требуют других доказательств.
